# Release notes for 0.4.0

Package version: **0.4.0**.

This document describes the local v0.4.0 release candidate. It is not a
publication claim; hosted validation, tagging, and publication remain pending.

## Included foundation work

- Bounded, evidence-gated skill invocation and completion normalization across
  Codex, Claude Code, OpenCode, and Antigravity event shapes.
- Explicit handling for unavailable, unobserved, failed, malformed, orphaned,
  ambiguous, and conflicting skill evidence without persisting skill contents,
  prompts, transcripts, or tool output.
- Fixture and regression coverage for skill lifecycle parsing, privacy bounds,
  timing, and failure-closed behavior.
- Opt-in local task metrics and a private telemetry mapping boundary that keeps
  external record keys and task identifiers out of public telemetry and task
  state.
- CI coverage for release branches, hermetic tests, package checks, knowledge
  validation, and optional cmux probing when a runner has a reachable cmux
  instance.
- Updated public documentation for the telemetry and skill evidence limits.

## Validation and limits

The local candidate passes formatting, the complete locked test suite, Clippy
with warnings denied, knowledge lint, and whitespace checks. Live provider
conformance, source/digest attribution for loaded skills, private tracker
aggregation, quota-aware Antigravity scheduling, and plugin ablation remain
explicit follow-up work. No paid-model evaluation is required by the release
checks. Hosted checks, security scan review, merge, and tag publication remain
release gates.
