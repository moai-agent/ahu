# Release notes for 0.5.0

Package version: **0.5.0**.

Version 0.5.0 was merged in [PR #6](https://github.com/moai-agent/ahu/pull/6),
tagged with the signed annotated tag `v0.5.0`, and published as a [GitHub
release](https://github.com/moai-agent/ahu/releases/tag/v0.5.0). The Cargo
package remains marked `publish = false` and was not published to crates.io.

## CLI and doctor updates

- Launch a registered agent directly with `ahu @agent [prompt]`. With no
  prompt, the interactive launcher opens with that agent selected. The
  `ahu launch @agent` form remains supported.
- The top-level help now highlights `ahu doctor`, `ahu agents`, and `ahu tasks`.
  Detailed `ahu inventory`, `ahu hygiene`, and `ahu diff` commands remain
  available.
- `ahu doctor` reports repository and configuration status, harness readiness,
  configured hooks and plugins, telemetry endpoint reachability, hygiene review
  cadence, bundled skill verification, agent drift, and cmux integration.
- `ahu agents` shows configured harnesses and models with drift status. `ahu
  tasks` presents a compact task list with relative worktree paths.

## Validation and limits

Local formatting, build, the complete locked test suite, Clippy with warnings
denied, skill checks, OKF knowledge lint, prose lint, dependency policy, package
contents, and Markdown links passed. The opt-in live cmux suite also passed
against a reachable cmux instance. Prose lint reported existing warnings and
suggestions but no errors.

The cargo-deny security scan found no advisories, banned dependencies,
disallowed licenses, or disallowed sources. It reported five duplicate-version
warnings for transitive crates; the dependency policy treats these as review
warnings. Manual review of the v0.5.0 CLI changes found no production security
issue.

Hosted Linux and macOS checks, CodeQL, dependency policy, release boundary,
prose, and live cmux checks passed. The release PR was reviewed and merged, and
the signed tag and GitHub release were verified on origin. The website install
command is pinned to the `v0.5.0` tag.
