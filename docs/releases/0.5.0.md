# Release notes for 0.5.0

Package version: **0.5.0**.

This document describes the local v0.5.0 release candidate. It is not a
publication claim; hosted validation, merge, tagging, and publication remain
pending.

## CLI and doctor updates

- Launch a registered agent directly with `ahu @agent [prompt]`. With no
  prompt, the interactive launcher opens with that agent selected. The
  `ahu launch @agent` form remains supported.
- The top-level help now highlights `ahu doctor`, `ahu agents`, and `ahu tasks`.
  Detailed `ahu inventory`, `ahu hygiene`, and `ahu diff` commands remain
  available.
- `ahu doctor` reports repository and configuration status, harness readiness,
  configured hooks and plugins, telemetry endpoint reachability, hygiene review
  cadence, bundled skill verification, agent drift, and cmux integration.
- `ahu agents` shows configured harnesses and models with drift status. `ahu
  tasks` presents a compact task list with relative worktree paths.
- The MCP interface exposes bounded bundled skill verification and setup tools.

## Validation and limits

Local formatting, tests, lint, dependency policy, package checks, and security
review are in progress. Hosted checks, review, merge, tag creation, and
publication remain release gates.
