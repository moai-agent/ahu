# Release notes for 0.6.0

Package version: **0.6.0**.

This document describes the local v0.6.0 release candidate. Merge, hosted
validation, tagging, and publication remain pending.

## Agent tooling and MCP

- Add model-agnostic typed decisions through `ahu_typed_decide`, with a local
  Ollama decision-service adapter and validated choice, score, and probability
  questions.
- Expand ahu MCP telemetry for tool discovery, calls, errors, skill use, typed
  decisions, and token observations. Keep payloads out of the local evaluation
  records and report incomplete telemetry as incomplete evidence.
- Make MCP task inspection and agent guidance more consistent across harnesses.
- Keep ahu's development-only skills out of MCP bundles delivered to other
  repositories.

## Local agent evaluations

- Add OKF Markdown evaluation cases and suites, deterministic answer scoring,
  optional blinded agent evaluators, and repeated candidate runs.
- Capture evaluation OTel locally and correlate MCP activity with task attempts.
- Add comparison tables, token and timing coverage, evaluator fingerprints,
  confidence intervals for binary rates, and explicit failure accounting.
- Validate typed answer ranges and continue the run matrix when a candidate
  fails to produce a valid answer.

## CLI and documentation

- Improve `ahu tasks`, `ahu agents`, and `ahu doctor` output, including compact
  terminal layouts and clearer drift details.
- Remove the redundant `ahu diff` command and align coordinator shortcuts on
  their configured models and approval behavior.
- Update the public documentation for MCP decisions, evaluation cases,
  telemetry coverage, and the terminal report.

## Validation and limits

Local formatting, the locked offline Rust test suite, Clippy, Python tests,
knowledge checks, dependency policy, and package-boundary checks pass. The Rust
suite includes MCP typed-decision fixtures and a complete evaluation run with local
OpenTelemetry capture. Manual security review found no release-blocking issue in the
decision address boundary, response limits, telemetry projection, or evaluation artifact
handling. A live `ahu mcp serve` call passed through the decision adapter to
local `gemma4:12b` and returned the expected classification. `cargo deny` found
no advisory, license, source, or banned-package
violation. Duplicate detection denies new versions, with five exact and
documented exceptions for incompatible transitive dependency requirements.
`cargo audit` is not installed, so the advisory result comes from `cargo deny`.
The project declares the MIT license in Cargo metadata and includes the license
text in the repository and packaged source.

Hosted checks and optional live cmux checks are pending. This candidate has not been
merged, tagged, or published.
