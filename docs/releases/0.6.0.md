# Release notes for 0.6.0

Package version: **0.6.0**.

This document describes the unpublished v0.6.0 candidate. Hosted validation,
tagging, and publication remain pending.

## Agent tooling and MCP

- Add model-agnostic typed decisions through `ahu_typed_decide`, using TypeSafe
  Jev over HTTPS with validated choice, score, and probability questions. Read
  `TYPESAFE_API_KEY` from the MCP environment or a protected local `.env` file;
  keep credentials out of committed configuration and telemetry.
- Apply one shared rubric to up to 20 items in a compact decision request.
  Validate expanded requests before provider access and preserve item IDs in
  typed answers. The bundled skill explains when to batch and when to answer
  directly, including the cost of an extra agent turn.
- Expand ahu MCP telemetry for tool discovery, calls, errors, skill use, typed
  decisions, and token observations. Keep payloads out of the local evaluation
  records and report incomplete telemetry as incomplete evidence.
- Make MCP task inspection and agent guidance more consistent across harnesses.
- Keep ahu's development-only skills out of MCP bundles delivered to other
  repositories.

## Local agent evaluations

- Add OKF Markdown evaluation cases and suites, deterministic answer scoring,
  optional blinded agent evaluators, and repeated candidate runs.
- Capture evaluation OTel locally and correlate MCP activity with task attempts.
- Add comparison tables, token and timing coverage, evaluator fingerprints,
  confidence intervals for binary rates, and explicit failure accounting.
- Validate typed answer ranges and continue the run matrix when a candidate
  fails to produce a valid answer.
- Measure decision request format and argument bytes through OTel. Preserve
  measured-call coverage and failed attempts in records and the CLI report.
- Add a [batch comparison corpus](../../evals/batching/README.md) and an
  [evaluation guide](../evaluations.md) for comparing instructions, skills and
  decision policies without awarding answer credit for tool use.

## CLI and documentation

- Improve `ahu tasks`, `ahu agents`, and `ahu doctor` output, including compact
  terminal layouts and clearer drift details.
- Remove the redundant `ahu diff` command and align coordinator shortcuts on
  their configured models and approval behavior.
- Consolidate project onboarding in `ahu setup`, with detected harnesses, model
  selection, development agents, skills, and MCP configuration.
- Replace inventory and hygiene commands with committed context locking and
  the agent context critic skill.
- Update the public documentation for MCP decisions, evaluation cases,
  telemetry coverage, and the terminal report.

## Validation and limits

Release preparation includes formatting, Rust tests and coverage, Clippy,
Python skill checks, knowledge validation, dependency policy, and package
boundary checks. Automated decision tests use synthetic provider responses.
Local live validation also exercised Codex with Jev across 18 comparison trials
and a fresh smoke test. See the [decision eval findings](../decision-eval-findings.md)
for observed request-size improvements, overhead, and a rejected optimization.
These checks do not establish general speed or token savings, or validate every
supported harness against the live provider.

Coverage remains below the requested 95% project target; the latest complete
measurement was 94.18%; it has not been refreshed for the decision batch changes.
Hosted checks and optional live cmux checks remain
pending. Version 0.6.0 has not been tagged or published.
