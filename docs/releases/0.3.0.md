# Release notes for 0.3.0

Package version: **0.3.0**.

This document describes the local v0.3.0 release candidate. It is not a
publication claim; the release tag and hosted validation remain pending.

## Included framework work

- Read-only MCP inspection tools for repository agents and tasks, with durable
  MCP Tasks handles, capability negotiation, cancellation, input round trips,
  and exact/unique-prefix task references.
- Bundled repository skills delivered under the canonical `.agents/skills/`
  tree. Setup is additive, refuses changed files and symlink redirection, and
  never creates a duplicate `.claude/skills/` tree.
- Cross-harness skill verification evidence for OpenCode, Codex, Claude Code,
  and Antigravity, with documented discovery limits and a portable skill
  contract.
- Immutable agent and task references, coordinator identity metadata, and
  repository-scoped cmux grouping across linked checkouts and windows.
- Headless task lifecycle, cancellation, resume, inspection, bounded native
  integration evidence, and explicit unknown-state reporting.
- Expanded task configuration inheritance, security confinement, terminal
  output safety, knowledge validation, and cross-harness regression coverage.

## Validation and limits

The final release gate must run formatting, Clippy with warnings denied, the
complete locked test suite, skill checks, OKF validation/lint, and prose lint.
The CI workflows define Ubuntu 24.04 and macOS 14 checks, a package and local
Markdown-link boundary check, and an opt-in live cmux probe on macOS when the
hosted runner provides cmux; hosted results are required before tagging. Live
provider and native hook behavior remains bounded by the evidence documented in
[the reference](../reference.md) and [skill verification](../skill-verification.md).
ahu does not claim that synthetic fixtures establish authenticated provider
conformance.

Website agent delivery, activity visualization, and DeepSeek support are
explicitly deferred to v0.4. Plugin ablation, Antigravity quota-aware
selection, and mobile access remain backlog explorations.
