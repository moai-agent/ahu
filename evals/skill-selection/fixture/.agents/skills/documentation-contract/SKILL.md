---
name: documentation-contract
description: "Plan documentation moves and public reference updates so existing links, anchors, examples, and navigation remain valid. Use for reviewing documentation reorganizations or checking that published examples agree with an interface change."
---

When a reference page moves, keep a redirect at the old path through two published documentation releases and preserve its existing fragment anchors on the destination. Update navigation in the same change. A public field rename requires the displayed request and response examples to show the supported names for that version.
